# LogiSuite TMS — Frontend

Next.js 16 (App Router), Tailwind v4, shadcn/ui, Framer Motion, TanStack
Table y deck.gl + MapLibre. Ver el README de la raíz del repositorio para la
arquitectura completa y el despliegue con Docker.

```bash
npm install
npm run dev          # requiere la API en http://localhost:8000 (API_INTERNAL_URL)
npm run typecheck
npm run lint
npm run build
```
